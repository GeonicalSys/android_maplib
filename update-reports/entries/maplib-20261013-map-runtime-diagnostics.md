why: Общий HTTP 503 и стек ожидания рендера не показывали этап и нагрузку, на которых приложение остановилось

Локальный сервер различает переполнение очереди и нехватку памяти, выдаёт ID
отказа и фиксирует длительности этапов обработки тайла. Независимый наблюдатель
сохраняет состояние задержавшегося запроса к карте даже при блокировке интерфейса.
Снимок ограничен по размеру, сохраняет версию процесса и доступен после restart;
быстрые успехи не пишутся, повторы учитываются без заполнения журнала.
